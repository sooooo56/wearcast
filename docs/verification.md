```text

✔ 서버: 키가 없으면 LLM을 부르지 않고 503
✔ 서버: 모델 이름이 없으면 503 (코드에 기본 모델을 넣지 않음)
✔ 서버: mock 제공자로 흐름 확인 -> 200, 검증 통과한 문장
✔ 서버: 같은 IP에서 10분에 20회 넘게 부르면 429
✔ 검증: 입력에 없는 숫자, 300자 초과, 한글 없는 문장은 거부
✔ 클라이언트: AI 성공 -> 캐시에 저장, 다음엔 바로 AI 문장 (재요청 없음)
```

# WEARCAST

> 오늘 날씨 말고, 오늘 뭘 입을지 알려줘.

날씨·대기질 실데이터(Open-Meteo)를 받아 **외출 시간대**에 맞는 옷차림과 준비물을 추천하는 모바일 우선 웹앱입니다.
옷/준비물 선택은 규칙 엔진이 정하고, LLM(Claude)은 추천 이유 문장만 씁니다.

## 화면

| WEATHER | OUTFIT | CHECKLIST |
|---|---|---|
| 지금 기온·체감·최고/최저, 시간대 6칸, 강수확률·풍속·자외선·미세먼지 | 외출 시간대 기준 아우터/상의/하의/신발(+방한용품)과 추천 이유 | 우산·자외선 차단제·마스크 등 준비물 체크리스트 |

- 세 화면은 가로로 넘깁니다 (모바일 스와이프, PC는 드래그·이전/다음 버튼·방향키).
- 배경은 현재 날씨와 낮/밤에 따라 9가지 테마로 바뀝니다. 구름은 캔버스로 그린 그림이 흐르고, 비·눈·별·번개는 깊이감 있는 캔버스 효과입니다. 가랑비~폭우, 약한 눈~눈보라는 날씨 코드의 강도를, 빗줄기 기울기와 구름 속도는 풍속을 따릅니다. `prefers-reduced-motion`이면 효과가 멈춥니다.
- 외출 시간대(낮 08~19 / 저녁 18~23 / 직접 설정)가 끝났으면 자동으로 **내일** 기준으로 추천합니다.

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm run dev:phone    # 같은 와이파이의 휴대폰에서 접속 (터미널에 나오는 Network 주소)
npm test             # 규칙 엔진·경계 시각·AI 대체 흐름 자동 테스트
npm run scenarios    # 시나리오별 추천 결과 표 출력
```

데모 데이터: 지역 선택 창 아래 "데모 데이터로 보기" 또는 주소에 `?demo=rain` (화면에 "데모 데이터" 배지 표시).

## 환경변수 (AI 이유 문장)

`.env.example`을 참고해 `.env.local`(로컬) 또는 Vercel 프로젝트 설정에 넣습니다. 키가 없거나 틀려도 앱은 **규칙 기반 설명**으로 정상 동작합니다.

| 이름 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | Anthropic API 키. 서버리스 함수(`api/explain.js`)에서만 사용, 브라우저로 보내지 않음 |
| `LLM_MODEL` | 모델 이름 (예: `claude-opus-5-5`). 코드에 넣지 않음 |
| `LLM_EFFORT` | 생각 깊이, 기본 `low` |
| `LLM_PROVIDER` | `anthropic`(기본) 또는 `mock`(키 없이 흐름 확인용) |

## 구조

```
src/
  api/      Open-Meteo 호출 (지오코딩, 예보, 대기질)
  logic/    요약(summarize) → 옷차림(outfit) · 준비물(checklist) → 이유 문장(explain), 모든 기준값은 thresholds.js
  ui/       세 화면, 테마, 지역/시간대 선택
  data/     날씨 코드·아이템 라벨·데모 샘플 데이터 (실데이터와 분리)
api/explain.js   Vercel 서버리스: LLM 이유 문장 (입력/출력 검증, 호출 제한)
tests/           node:test 자동 테스트
docs/verification.md  시나리오별 추천 결과와 테스트 기록
```

## 데이터를 다루는 원칙

- 받지 못한 값은 만들지 않고 "정보 없음"으로 표시합니다. API가 실패하면 오류 화면과 다시 시도 버튼을 보여줍니다.
- 체감온도·미세먼지는 **모델 예측값**입니다. 황사는 공식 특보가 아니라 "가능성 참고"로만 표시합니다.
- 미세먼지 "나쁨" 기준(PM10 81, PM2.5 36 ㎍/㎥)은 에어코리아 예보 등급표로 확인했습니다. 단, 공식 등급은 일평균 기준이고 앱은 시간별 최댓값 예측과 비교합니다.
- LLM 문장은 입력에 없는 숫자가 들어 있으면 서버와 클라이언트에서 모두 거부하고 규칙 기반 문장을 씁니다.

## 배포 (Vercel)

1. 이 폴더를 GitHub 저장소로 올리거나 `npx vercel`로 바로 배포합니다. 프레임워크는 Vite로 자동 인식되고, `api/` 폴더는 서버리스 함수가 됩니다.
2. Vercel 프로젝트 설정 → Environment Variables에 위 환경변수를 넣습니다.
3. 배포 후 휴대폰에서 스와이프, iOS Safari 가장자리 뒤로 가기 제스처, 위치 권한 허용/거부를 확인합니다.
